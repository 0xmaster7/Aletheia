# Repository map

- `archive/` — preserved one-off utilities that are no longer part of the normal workflow.
- `benchmarks/` — benchmark drivers, including routing latency under `latency/`.
- `data/` — the released 13,425-question synthetic benchmark.
- `docs/` — evaluation report, project summary, TODO list, and reproducibility notes.
- `logs/` — dated reruns, ablation logs, and latency logs.
- `paper/` — paper source files and diagrams.
- `results/` — committed result JSON under `poc_results/` and imported baselines under `poc_results_backup_imported/`.
- `scripts/` — experiment, data-generation, validation, analysis, and shared library modules.

Root files include the project README, dependency requirements, environment template, and Git ignore rules.
